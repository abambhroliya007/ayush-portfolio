Golf Swing Analyzer

A full-stack computer-vision application that processes golf-swing videos, estimates body pose, calculates movement metrics, and presents actionable feedback.

01 · The problem

Why this needed to exist

Golfers can record their swing easily, but converting video into objective feedback about tempo, rotation, and stability normally requires manual coaching or specialized equipment.

02 · The solution

How I approached it

The analyzer processes uploaded video frame by frame, estimates body landmarks, derives biomechanical signals, and displays metrics and visual feedback through a web interface.

03 · Product

Core capabilities

  • Video upload and processing
  • Pose-landmark detection
  • Swing-phase analysis
  • Tempo estimation
  • Rotation and stability metrics
  • Annotated visual feedback
  • Full-stack results interface

The system turns raw video into understandable movement data, demonstrating an end-to-end computer-vision workflow rather than only a standalone model script.

04 · Architecture

How the system works

▶

Swing Video

The golfer uploads a recorded swing through the web interface.

UI

React Frontend

Handles upload, processing status, playback, and results visualization.

⚙

FastAPI Analysis Service

Receives video, manages frame extraction, runs pose analysis, and assembles the final metrics response.

✓

Swing Report

Returns annotated video insights, movement metrics, and practical feedback for the golfer.

▦

OpenCV

Decodes the video and prepares individual frames for analysis.

⌁

MediaPipe Pose

Detects body landmarks across the swing sequence.

∠

Metrics Engine

Calculates tempo, rotation, posture, and stability signals from landmarks.

✓

Feedback Layer

Converts raw measurements into understandable strengths and improvement areas.

1. InputUpload a golf-swing video.
2. ProcessExtract frames, estimate pose, and calculate biomechanical metrics.
3. DeliverPresent annotated visual results and actionable feedback.

05 · Engineering

Challenges solved

  • Maintaining landmark consistency across frames
  • Handling different video angles and lighting
  • Identifying meaningful swing phases
  • Converting coordinates into useful metrics
  • Managing video processing in a web workflow

06 · Reflection

What I learned

This project showed me how model outputs become valuable only after careful temporal processing, metric design, API integration, and user-centered presentation.

07 · Roadmap

Future improvements

  • Add club-path estimation
  • Optimize processing for mobile uploads
