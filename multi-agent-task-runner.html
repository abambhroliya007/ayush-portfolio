01 · The problem

Why this needed to exist

Complex requests are difficult to solve reliably with one prompt because planning, information gathering, execution, and quality control require different behaviors.

02 · The solution

How I approached it

AgentFlow divides the workflow among specialized agents and uses a graph-based orchestrator to control state, handoffs, and validation before returning the final response.

03 · Product

Core capabilities

  • Planner-agent task decomposition
  • Research-agent context gathering
  • Execution-agent solution generation
  • Validator-agent quality review
  • Shared workflow state
  • Conditional routing and retries
  • Interactive Streamlit interface

The project demonstrates how agent specialization and explicit orchestration can make multi-step AI work more transparent and dependable than a single unstructured generation call.

04 · Architecture

How the system works

◎

User Task

Provides the complex request and any constraints to the workflow.

UI

Streamlit

Starts the run and visualizes status, intermediate stages, and final output.

⚙

LangGraph Orchestrator

Maintains shared state, routes work between agents, and controls the completion and validation sequence.

✓

Validated Response

Returns the final answer only after the workflow has planned, executed, and reviewed the result.

P

Planner Agent

Breaks the request into an ordered, achievable execution plan.

R

Research Agent

Collects and organizes the context needed for each task.

E

Executor Agent

Produces the solution or artifact from the plan and research.

V

Validator Agent

Checks completeness, consistency, and quality before completion.

1. InputSubmit one complex task to the system.
2. ProcessRoute shared state through specialized agents and validation logic.
3. DeliverReturn a reviewed final response with a clear workflow trail.

05 · Engineering

Challenges solved

  • Designing useful agent boundaries
  • Passing state safely between nodes
  • Preventing circular or unnecessary agent loops
  • Handling incomplete intermediate outputs
  • Balancing autonomy with deterministic control

06 · Reflection

What I learned

This project taught me that agent quality depends heavily on orchestration, state design, and stopping conditions—not just the prompts assigned to each agent.
