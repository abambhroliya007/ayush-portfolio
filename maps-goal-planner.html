Maps: Goal Planner

An AI-powered route planner that converts natural-language goals into ranked destinations, alternatives, optimized multi-stop routes, and an interactive trip timeline.

01 · The problem

Why this needed to exist

Traditional map applications require users to know each destination before planning. A person with several errands must search, compare, choose, and order every stop manually.

02 · The solution

How I approached it

Maps: Goal Planner starts with intent. The user describes what they need to accomplish, and the application identifies errands, discovers nearby businesses, ranks candidates, stores alternatives, and creates an efficient route.

03 · Product

Core capabilities

  • Natural-language goal understanding
  • Structured intent extraction
  • Nearby place discovery
  • Business relevance ranking
  • Alternative stop selection
  • Multi-stop route optimization
  • Interactive map and trip timeline

This project was designed as a complete user workflow, not just a model demo. The interface, processing logic, and outputs work together to move the user from input to a clear, useful result.

04 · Architecture

How the system works

◎

User Goal

The user enters a starting address, time constraints, preferences, and a natural-language objective.

◈

Next.js Frontend

Collects input, manages UI state, displays alternatives, and renders the final map experience.

⚙

FastAPI Orchestrator

Coordinates AI reasoning, geocoding, business discovery, ranking, and route generation.

✓

Optimized Trip

Returns ranked stops, alternates, route geometry, travel summary, and an explainable timeline.

AI

OpenAI

Transforms free-form language into structured errands, categories, and planning constraints.

⌖

Nominatim

Geocodes the starting address and discovers nearby candidate businesses through OpenStreetMap.

★

Ranking Engine

Scores candidates using distance, category fit, intent relevance, and search confidence.

↝

OSRM + Leaflet

Generates route geometry and visualizes markers, stop order, and the interactive trip path.

1. Understand Convert human intent into structured planning data.
2. Decide Search, score, rank, and select the strongest destination set.
3. Deliver Return an efficient, explainable route that the user can interact with.

05 · Engineering

Challenges solved

  • Mapping abstract goals to business categories
  • Ranking imperfect place-search results
  • Keeping selected alternatives synchronized with map markers
  • Reducing route backtracking
  • Coordinating multiple external APIs

06 · Reflection

What I learned

This project combined product thinking with AI, geospatial services, ranking logic, frontend state, and backend integration. It showed me how AI can become one decision-making component inside a larger deterministic system.

07 · Roadmap

Future improvements

  • Add live traffic and business hours
  • Personalize recommendations
  • Support calendar and voice input
  • Add price-aware ranking
  • Enable dynamic rerouting and saved trips
